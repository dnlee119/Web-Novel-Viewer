# Web Novel Viewer

> **Codex AI 생성물 안내**
>
> 이 저장소의 작업물은 Codex AI를 이용해 생성했습니다.

Web Novel Viewer는 웹소설의 문장과 문단에 스크롤 연출을 더하는 **웹 뷰어와 에디터** 프로젝트입니다. 창작자는 원하는 구절에 이미지·대사·배경음과 효과를 배치하고, 독자는 자신의 속도로 읽거나 자동 재생을 선택할 수 있도록 기획하고 있습니다.

## 현재 상태

작품을 스크롤하거나 자동 재생으로 읽고, 에디터에서 원고를 수정해 미리 보거나 JSON으로 내보낼 수 있습니다. 정식 저장은 에디터를 삽입하는 사이트의 서버에 연결합니다. 공개 데모의 배포 상태는 GitHub Actions에서 확인할 수 있습니다.

[공개 뷰어](https://dnlee119.github.io/Web-Novel-Viewer/) · [공개 에디터](https://dnlee119.github.io/Web-Novel-Viewer/editor.html)

## 데모 실행

저장소 루트에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:8000/`을 엽니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

장면을 선택하거나 읽기 영역 안에서 스크롤합니다. 자동 재생의 속도를 바꾸고 일시정지할 수 있습니다. **작품 편집기 열기**를 선택하거나 `http://localhost:8000/editor.html`을 열면 같은 샘플을 편집할 수 있습니다. 데모에서는 JSON 사본과 브라우저 임시 저장을 이용할 수 있습니다.

에디터의 장면 목록에서 **해당 장면 삭제**로 선택한 장면을 지울 수 있습니다. 장면을 우클릭하거나 **⋯** 버튼을 누르면 선택·이동·삭제 메뉴가 열립니다. 삭제 후 **실행 취소**로 복구할 수 있습니다.

객체를 누르면 속성 패널이 열립니다. 장면 복사·붙여넣기는 **⋯** 메뉴, 객체 복사·붙여넣기는 편집 도구 모음에서 할 수 있습니다.

## 에디터 삽입

호스트 페이지에 편집기 컨테이너를 만들고 배포 디렉터리에서 모듈을 불러옵니다. URL은 해당 사이트가 운영하는 API로 지정합니다.

```js
import { mountEditor } from "./editor/editor.js";

const editor = mountEditor(document.querySelector("#editor"), {
  getUrl: "/api/works/42",
  postUrl: "/api/works/42",
  draftKey: "42",
});
await editor.ready;
```

GET은 작품 JSON을 반환하고 POST는 그 형식으로 된 본문을 받습니다. 여러 사용자가 같은 브라우저를 공유하는 사이트에서는 계정과 작품을 구분하는 임시 저장 키를 사용합니다. 호스트가 화면을 제거할 때는 `editor.destroy()`를 호출합니다.

## 구현 계획

1. **뷰어** — 문장과 문단을 스크롤 그룹으로 구성합니다. 역스크롤하거나 장면을 건너뛰면 도착 지점의 화면을 복원합니다.
2. **재생과 미디어** — 자동 재생과 이미지·대사·배경음을 연결합니다. YouTube 플레이어는 독자가 재생을 선택하면 불러옵니다.
3. **에디터와 외부 연동** — 일반 웹 문서처럼 글을 쓰고 선택한 구절에 연출을 추가할 수 있게 합니다. 뷰어와 에디터는 각자 원하는 웹사이트에 삽입할 수 있는 경량 JavaScript ES 모듈로 제공할 계획입니다. 작품은 사이트의 서버에서 JSON으로 관리하며, GET으로 불러오고 에디터에서 POST로 저장합니다.
4. **UI 현대화 및 개선** — 뷰어와 에디터를 시범 사용한 결과를 바탕으로 화면 구성, 조작 흐름, 접근성을 개선합니다.

화면은 실제 삽입 영역과 입력 방식에 맞춰 구성합니다. 웹 브라우저와 WebView 등에서 동작하도록 설계하며, 지원 범위는 구현 후 확인합니다. 사용자 제작 효과는 보안과 결과물 품질을 검토한 뒤 별도 확장으로 다룰 예정입니다.

## 작업 관리와 배포

- 작업 제안과 진행 상황은 [GitHub Issues](https://github.com/dnlee119/Web-Novel-Viewer/issues)에서 관리합니다. 변경은 작업별 브랜치에서 진행하고 `main`으로 Pull Request를 엽니다.
- `site/index.html`이 준비되면 `main`의 `site/` 변경을 GitHub Pages에 자동 배포합니다. 실행 결과는 [GitHub Actions](https://github.com/dnlee119/Web-Novel-Viewer/actions)에서 확인할 수 있습니다.
